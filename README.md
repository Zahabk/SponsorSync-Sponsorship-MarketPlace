## 📌 Overview

SponsorSync is a full-stack MERN application that simplifies the process of connecting **Event Organizers** with **Sponsors**.

Traditionally, organizers spend significant time searching for sponsors through emails, social media, and personal contacts, while sponsors struggle to discover relevant events that align with their brand.

SponsorSync solves this problem by providing a centralized platform where organizers can showcase events, sponsors can submit sponsorship proposals, and both parties can communicate efficiently.

The platform includes secure authentication, profile management, proposal management, and cloud-based media storage, making the sponsorship process faster, transparent, and more organized.

# ✨ Features

* Secure JWT Authentication

* Protected Routes

## 🎯 Organizer Features

* Create and manage event listings
* Upload event banner
* Edit/Delete events
* View sponsorship proposals

* Accept or reject sponsor proposals
* Manage organizer profile

## 💼 Sponsor Features

* View complete event details
* Send sponsorship proposals

* Update sponsor profile
